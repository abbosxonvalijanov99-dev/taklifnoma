🔐 4-QADAM Kirish Nazorati (IAM / RBAC) va Rollar Taqsimoti

Loyiha sozlamalaridan «Collaborators» menyusiga kiring va «Add people» orqali guruhdoshingizga taklifnoma yuboring.

Rol (Role) Huquq darajasi Xavfsizlik maqsadi
Read Faqat ko'rish va klonlash Audit o'tkazuvchilar va kuzatuvchilar uchun
Write Kod yuklash va tahrirlash Jamoa dasturchilari uchun
Admin To'liq boshqaruv (o'chirish, ruxsat berish) Faqat loyiha egasi va yetakchi mutaxassis uchun

🛡️ 5-QADAM Kod Himoyasi Siyosati (Branch Protection)

Asosiy kodni (main) ruxsatsiz o'zgartirish yoki tasodifan o'chirib yuborishdan himoyalash:

  1. Settings → Branches bo'limiga o'ting.
  2. «Add branch ruleset» (yoki Add rule) tugmasini bosing.
  3. Target branch: main deb belgilang.
  4. «Restrict deletions» va «Require a pull request before merging» bandlarini faollashtirib, saqlang.

✅ 3. Talaba O'zini Tekshirish Nazorat Ro'yxati (Checklist)

  • ✓ Deploy qilindi: Sayt GitHub Pages orqali internetda ochiq ochilmoqda.
  • ✓ RBAC joriy etildi: Collaborators bo'limida kamida 1 nafar foydalanuvchiga taklifnoma yuborildi.
  • ✓ Xavfsizlik yoqildi: main tarmog'i uchun Branch Protection faol holatga keltirildi.
